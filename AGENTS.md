# Repository agent instructions

## Portfolio mobile releases

Use the [mobilereleases registry and dashboard](https://github.com/killjoy00/mobilereleases) and its [release request instructions](https://github.com/killjoy00/mobilereleases/blob/main/mobile-releases/RELEASE_REQUESTS.md) for mobile release work. Existing mobile releases are managed through EZTrivia; use the current version-specific Android adapter only after inspecting its guards. Existing app-specific tests, release approval and exact-artifact requirements take precedence. Do not publish to production without explicit owner approval. Report signed builds, uploads, testing, review and public availability separately, and never expose credentials or private account information.
